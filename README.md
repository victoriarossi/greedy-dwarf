# Greedy Dwarf

Welcome to **Greedy Dwarf**! In this game, you navigate a treacherous dragon's lair, collecting as much treasure as possible before time runs out. Watch out for the dragon and strategically balance treasure collection with your movement speed!

## Game Objective

Navigate the Dragon's Lair and collect as much treasure as possible before time runs out. In later levels, you must also avoid a dangerous dragon that guards the lair. The more treasure you collect, the slower your movement will become, so plan your moves wisely!

---

## How to Play

1. **Control Your Dwarf**: Use the arrow keys or WASD to move through the lair.
2. **Collect Treasure**: Approach and collect treasures scattered throughout the lair to increase your score.
3. **Avoid Obstacles**: Avoid walls and locked doors as you explore.
4. **Plan Your Route**: Carrying too much treasure will slow you down, so strategize your path carefully!
5. **Dragon Threat**: As you progress, the dragon becomes a real threat—avoid it at all costs.

---

## Features

- **Customizable Lair**: The lair is defined by a flexible map file, offering unique environments and challenges.
- **Strategic Play**: Balance speed and treasure collection to escape in time.
- **Responsive UI**: The game features a modern, responsive interface built with React and Bootstrap.

## Installation

To get started with **Greedy Dwarf**, you'll need to have [Node.js](https://nodejs.org/) and [npm](https://www.npmjs.com/) installed on your machine.

1. Clone this repository:
   ```bash
   git clone https://github.com/cs-440-at-uic/440-Group-6-Fall-2024.git
    ```

2. Navigate to the project directory:
    ```bash
    cd Coding\ Project/greedy-dwarf
    ```

## Running the Game
To run the game locally:

1. Start the development server:
    ```bash
    npm start
    ```
2. Open your browser and navigate to http://localhost:3000.

You should see the Greedy Dwarf home page, where you can start the game.
